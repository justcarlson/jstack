# jstack

Agent skills for shipping real pull requests across Claude Code, Codex, Antigravity, OpenCode, and T3 Code. Built as an independent companion and patched distribution of Theo Browne's [t3dotgg/tstack](https://github.com/t3dotgg/tstack).

Not affiliated with Upstash JStack or OpenJDK `jstack`.
